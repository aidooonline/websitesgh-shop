3 · The Attribution Engine

Every Order, Traced To Source  Live

The moat. It closes the WhatsApp gap that blinds normal ecommerce tracking.
Capture
gclid / gbraid / wbraid + UTMs in 90-day first-party cookies. Every WhatsApp tap logged via beacon: product, price, placement, campaign.
Ref-code loop
Each tap stamps a WG-XXXX code into the message. The code the customer sends IS the row in your admin. Chats tie to clicks with zero guesswork.
Convert & export
On-site orders auto-convert. One-click Sold on WhatsApp sales. Exports the exact Google Ads offline-conversion CSV, incremental, never double-sent.
Close-rate intelligence
Taps / sold / rate per product, 30 days.
Follow-up radar
Warm chats going cold, flagged 1-7 days.
Meta Pixel seeded
Audiences fill before any Meta spend.
